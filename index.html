Начнём создавать

Ваш ИИ-ассистент будет жить в Telegram — для него нужно создать бота. Давайте создадим его за минуту через BotFather.

  1. 1Зайдите в BotFather (бот в Telegram).
  2. 2В нижнем левом углу нажмите кнопку Open.
  3. 3Нажмите + Create a New Bot.
  4. 4В графе Bot Name напишите имя своего ассистента. В графе t.me/ напишите любое название латиницей и добавьте в конце _bot.
  5. 5Добавьте ассистенту фотографию — это его аватарка в Telegram.
  6. 6Нажмите Create Bot.
  7. 7Зайдите в этого бота и скопируйте ключ, нажав синюю кнопку Copy.

Что произойдёт дальше

Обычно приложение закрывается сразу после отправки. Дальше установка идёт уже в переписке с ботом, он присылает статус по каждому шагу. Единственное, что понадобится от вас — один раз войти в свой аккаунт Claude по ссылке, которую пришлёт бот.

  1. 1Подключение к серверу по ключу
  2. 2Загрузка и установка Tasker
  3. 3Подключение вашего Telegram-бота
  4. 4Вход в аккаунт Claude по ссылке
  5. 5Запуск личного агента

Обычно вся установка занимает 5–10 минут. Бот присылает короткий отчёт по каждому шагу — если что-то пойдёт не так, вы сразу увидите, на каком именно.

И последнее — про доступ к серверу. В конце установки вход по паролю на нём отключается совсем: пароль, который вы вводили, больше никуда не подходит. Наш SSH-ключ на сервере остаётся — им мы выпускаем обновления и помогаем, если что-то сломается. Захотите закрыть и его — удалите нашу строку из файла /root/.ssh/authorized_keys: агент продолжит работать сам, но удалённо помогать мы уже не сможем.

Конец раздела — бот напишет, когда агент будет готов.
