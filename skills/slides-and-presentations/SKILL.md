# Создание слайдов и презентаций

Этот скилл ставится клиенту как допфункция «Создание слайдов и презентаций»
(см. [index.html](../../index.html) экран «Дополнительные функции», карточка
`addon-panel-slides`). Он работает на личном сервере клиента — то же окружение,
что и остальные библиотеки навыков PROha, — и не звонит наружу ни к каким
платным API: колода собирается локально через `python-pptx`, готовый файл
агент отправляет клиенту тем же способом, каким обычно возвращает файлы в
Telegram-чате.

## Когда применять

Клиент просит: сделать презентацию/слайды/питч-дек/отчёт в виде слайдов,
обновить существующую колоду, добавить/убрать слайд, поменять текст на
слайде. Если просьба — про видео или моушн-графику, это другая допфункция
(«Анимации и моушн-графика»), не эта.

## Что нужно узнать перед стартом

Если клиент не сказал сам — коротко уточнить (не растягивать в анкету,
достаточно одного сообщения):

1. **Тема и цель** — о чём презентация и зачем (питч инвестору, отчёт по
   проекту, обучающий материал, продажа услуги).
2. **Аудитория** — кто будет смотреть (принято решение сокращает количество
   слайдов и упрощает язык).
3. **Примерный объём** — если не назван, по умолчанию 8–12 слайдов
   (титул + 6–10 содержательных + финальный слайд).
4. **Материалы** — есть ли готовый текст/тезисы/данные, которые нужно
   уложить в слайды, или собрать структуру с нуля по теме.
5. **Оформление** — просить конкретный брендинг (цвета, логотип) не
   обязательно; без указаний использовать нейтральный шаблон ниже.

Не задавай все пять пунктов сразу списком — задай только то, чего
недостаёт, и переходи к сборке.

## Как собирать

1. **Черновик структуры сначала текстом.** Составь план: заголовок каждого
   слайда + 2–4 буллета содержания. Один слайд — одна мысль, не более
   ~6 строк текста на слайде (иначе с него читают, а не слушают).
2. **Стандартные роли слайдов**, если клиент не просил иначе:
   - Титульный (заголовок + подзаголовок/автор)
   - Проблема/контекст
   - Решение/суть
   - 3–5 содержательных слайдов по теме
   - Итог/следующие шаги
   - Финальный (контакты/спасибо)
3. **Собери файл скриптом**, не вручную через UI (на сервере клиента нет
   PowerPoint). Пример на `python-pptx` — при первом запуске установи
   пакет, если его ещё нет в окружении:

```bash
pip show python-pptx >/dev/null 2>&1 || pip install python-pptx
```

```python
from pptx import Presentation
from pptx.util import Inches, Pt

deck = [
    {"title": "Название презентации", "subtitle": "Подзаголовок или автор"},
    {"title": "Заголовок слайда", "bullets": ["Тезис один", "Тезис два", "Тезис три"]},
    # ... остальные слайды по составленной структуре
]

prs = Presentation()  # пустой шаблон — 4:3/16:9 из коробки, без лишних сетевых зависимостей
title_layout = prs.slide_layouts[0]   # титульный layout (заголовок + подзаголовок)
content_layout = prs.slide_layouts[1]  # layout «заголовок + список»

for i, slide_spec in enumerate(deck):
    layout = title_layout if i == 0 else content_layout
    slide = prs.slides.add_slide(layout)
    slide.shapes.title.text = slide_spec["title"]
    if i == 0:
        slide.placeholders[1].text = slide_spec.get("subtitle", "")
    else:
        body = slide.placeholders[1].text_frame
        body.clear()
        for j, bullet in enumerate(slide_spec.get("bullets", [])):
            p = body.paragraphs[0] if j == 0 else body.add_paragraph()
            p.text = bullet
            p.font.size = Pt(20)

prs.save("presentation.pptx")
```

   Встроенный шаблон `Presentation()` уже даёт читаемое базовое
   оформление — этого достаточно по умолчанию. Кастомную тему/цвета
   подключать только если клиент явно просил брендинг (через
   `prs = Presentation("template.pptx")` с заранее подготовленным
   шаблоном, а не генерацией темы с нуля каждый раз).

4. **Не переусложняй вёрстку** без запроса: без явной просьбы не встраивай
   изображения/графики из внешних источников (лишний сетевой вызов,
   которого этот скилл сознательно избегает) — только текстовые слайды.
   Если у клиента есть свои картинки/логотип (прислал файлом в чат) — их
   можно вставить через `slide.shapes.add_picture(...)`.
5. **Проверь перед отправкой**: открой количество слайдов = ожиданию,
   заголовки не пустые, на слайдах с буллетами текст не обрезан слишком
   длинными строками (короче — лучше).

## Как отдать результат

Отправь получившийся `.pptx` клиенту в Telegram тем же способом, каким
агент обычно возвращает файлы (как документ, не как текст) — с коротким
сообщением, что это черновик и он охотно поправит по замечаниям.
Не публикуй и не рассылай файл никуда, кроме личного чата клиента.

## Ограничения, о которых стоит сказать клиенту при первом использовании

- Дизайн — из встроенного нейтрального шаблона `python-pptx`, не копия
  фирменного стиля клиента, если шаблон не подготовлен заранее.
- Анимации переходов между слайдами и сложная моушн-графика — это другая
  допфункция («Анимации и моушн-графика»), не входит сюда.
- Файл собирается локально на сервере клиента — если нужны сложные
  диаграммы из живых данных (Excel/Sheets), спросить, откуда брать данные,
  прежде чем начинать.
